# 批量取链回归检查

使用 Node.js 18+，运行 `npm test`，不需要网盘账号或额外测试依赖。
安装项目开发依赖后，运行 `npm run check` 执行上游 ESLint（带自动修复）；
仅检查可运行 `npx --no-install eslint .`。

测试从用户脚本提取实际 base 与网盘 getFilesUrl，隔离在 VM 中执行，
不执行脚本初始化或访问真实网盘。声明/方法边界变化时会明确报错。
`LINKSWIFT_SOURCE` 可指定旧版本脚本路径，验证修复前的失败。

- 百度：50 文件批次边界、业务错误后继续、空值/畸形响应、令牌过期、
  按 ID 匹配乱序/缺失结果、缓存命中与过期、目录过滤。
- 阿里：并发响应逆序完成时各文件链接独立、缓存按 fileId 写回、
  单文件失败不污染成功文件、异常响应和令牌过期。
- HTTP：仅绑定 `127.0.0.1`，以 Node HTTP 适配 GM 传输接口，保留实际
  base.get 的响应解析，检查业务错误 JSON 后下一批成功。

受限沙箱可能禁止本机 HTTP 连接，需要允许测试访问 loopback。
这些检查未模拟浏览器 Cookie/UA 限制、DOM、真实网盘 API 或下载器安装环境。
不包含真实令牌、Cookie、密码或可用的签名下载链接。

本次仅修正返回结果归属和错误处理，保持现有 API、50/3 批次大小、请求间隔、
缓存 TTL、脚本版本及 AGPL 许可声明。共享下载安全改造另见上游 #509，
夸克递归目录与 NDM 分别已有 #480/#517，未在这里重复实现。
